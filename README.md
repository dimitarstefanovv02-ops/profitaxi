# ProfiTaxi

Mobile-first уеб приложение за таксиметрови шофьори: приходи, разходи и реална чиста печалба.

## Демо
- Шофьор: `ivan@demo.bg` / `demo123`
- Админ панел: `/admin` → `admin@profitaxi.bg` / `admin123`

В демо версията данните се пазят в браузъра (localStorage). Целият достъп до данни минава през `js/store.js`, който по-късно се заменя с истинска база (напр. Supabase) без промени по екраните.

## Структура
- `index.html`, `js/app.js` – приложението за шофьора
- `admin.html`, `js/admin.js` – админ панелът (отделен вход)
- `js/store.js` – слой за данни (демо: localStorage)
- `js/calc.js` – изчисления: печалба, постоянни разходи по дни, цел, прогноза, топлинна карта, рекорди
- `js/views/*` – екраните
- `sw.js`, `manifest.webmanifest` – инсталиране като приложение и работа без интернет

Без зависимости и без build стъпка: статични файлове, хоствани във Vercel.
